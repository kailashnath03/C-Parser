Supported C Language Grammar (EBNF Subset)

Clean, context-free LALR(1) grammar implemented in GNU Bison with zero shift/reduce and zero reduce/reduce conflicts.

program ::= { function_def | function_proto | declaration } function_def ::= type_spec_list IDENTIFIER '(' [params] ')' compound_stmt function_proto ::= type_spec_list IDENTIFIER '(' [params] ')' ';' params ::= param { ',' param } [ ',' '...' ] param ::= type_spec_list [ declarator ] declaration ::= type_spec_list declarator_list ';' declarator ::= [ '*' ] IDENTIFIER { '[' [expr] ']' } init_decl ::= declarator [ '=' assign_expr ] compound_stmt ::= '{' { declaration | statement } '}' statement ::= compound_stmt | expr ';' | ';' | 'if' '(' expr ')' statement [ 'else' statement ] | 'while' '(' expr ')' statement | 'do' statement 'while' '(' expr ')' ';' | 'for' '(' [expr|declaration] ';' [expr] ';' [expr] ')' statement | 'switch' '(' expr ')' compound_stmt | 'case' expr ':' | 'default' ':' | 'return' [expr] ';' | 'break' ';' | 'continue' ';' expr ::= assign_expr { ',' assign_expr } assign_expr ::= cond_expr | unary_expr assign_op assign_expr cond_expr ::= or_expr [ '?' expr ':' cond_expr ] or_expr ::= and_expr { '||' and_expr } and_expr ::= bitor_expr { '&&' bitor_expr } bitor_expr ::= xor_expr { '|' xor_expr } xor_expr ::= bitand_expr { '^' bitand_expr } bitand_expr ::= eq_expr { '&' eq_expr } eq_expr ::= rel_expr { ('==' | '!=') rel_expr } rel_expr ::= shift_expr { ('<' | '>' | '<=' | '>=') shift_expr } shift_expr ::= add_expr { ('<<' | '>>') add_expr } add_expr ::= mul_expr { ('+' | '-') mul_expr } mul_expr ::= cast_expr { ('*' | '/' | '%') cast_expr } cast_expr ::= unary_expr | '(' type_spec_list ')' cast_expr unary_expr ::= postfix_expr | ('++' | '--') unary_expr | ('+' | '-' | '!' | '~' | '&' | '*') cast_expr postfix_expr ::= primary_expr { '[' expr ']' | '(' [args] ')' | '.' Deliberate Simplifications & Limitations (Educational Subset)

  • Preprocessor: Directives like #include and #define are skipped lexically. Macro expansions are not performed.
  • User Defined Types: struct, union, and enum body definitions are excluded.
  • Typedef: Aliased type names via typedef are out of scope to avoid lexer feedback ambiguity.
  • Function Pointers: Complex declarators like int (*fp)(int) are omitted.
  • Semantic Analysis: Scope validation, symbol table bindings, and type coercion are compiler back-end tasks not evaluated here.
